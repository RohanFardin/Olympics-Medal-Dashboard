# Olympics Medal Dashboard  

## Overview  
This interactive visualization tool analyzes medal distributions in the Summer Olympics (1896–2024) using **Power BI**. The dashboard allows users to explore trends in gold, silver, and bronze medals across various dimensions such as:  
- **Sex**  
- **Sport**  
- **Medal Type**  
- **Individual Athlete Performance**  

With dynamic filtering and tailored visualizations, the dashboard offers insights into athlete performances and medal distributions spanning over a century.  

---

## Features  

### 1. Medal Distribution by Age  
- **Line Chart**: Displays the count of medals (Gold, Silver, Bronze) won across different age groups.  

### 2. Top Athletes  
- **Horizontal Bar Chart**: Highlights individual athletes with the highest number of medals, categorized by medal type.  

### 3. Medal Counts by Country  
- **Horizontal Bar Chart**: Visualizes the total number of medals won by each country, segmented by medal type.  

### 4. Filters for Enhanced Exploration  
- **Sport Selection**: Focus on specific sports (e.g., Athletics, Swimming).  
- **Year Selection**: Analyze medal trends for specific Olympics years.  
- **Sex Filter**: Filter data by male and female athletes.  
- **Medal Type**: View Gold, Silver, or Bronze medal distributions.  

---

## How to Use  

1. **Explore Medal Distributions by Age**  
   - Use the line chart to understand which age groups have been the most successful over the years.  

2. **Analyze Top Athletes**  
   - View the horizontal bar chart to see which athletes have earned the most medals and their distribution by medal type.  

3. **Examine Country Performance**  
   - Use the country-specific bar chart to identify leading nations in Olympic history.  

4. **Apply Filters**  
   - Tailor your analysis by selecting specific criteria, such as sport, year, sex, or medal type, to generate dynamic and relevant insights.
